# Security & Monitoring

## Security
- Keep secrets in environment/deployment secret storage.
- Never commit `.env`.
- Hash passwords securely.
- Use expiring JWTs.
- Validate all API inputs.
- Restrict CORS.
- Use HTTPS in production.
- Apply authorization checks.
- Do not expose database credentials to React.

## Monitoring
Track uptime, latency, error rate, MongoDB health, Ollama health, vector retrieval failures, CPU/RAM/disk usage.

Avoid logging passwords, tokens, API keys and unnecessary financial/personal information.
